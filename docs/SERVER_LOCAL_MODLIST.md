# Local full mod list

The authoritative local test order is stored in `modlist.txt` and `DeutschZ_Start_local.bat`.

`@RUSForma_vehicles` is loaded directly before `@DeutschZ_only_core`. Separate MenuZ, KotHZ Free and UiAdminZ entries are intentionally absent because their three DeutschZ PBOs are packaged in `@DeutschZ_only_core`.

The Workshop package remains separate and must be present on client and server. The mod list contains no duplicate entry.
