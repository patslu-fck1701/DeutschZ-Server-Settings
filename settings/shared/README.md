# Shared Settings

Gemeinsame Einstellungen für lokalen Testserver, DayZ Labs und LiveServer.

Vor dem Einfügen:

- Standarddatei nicht komplett kopieren, wenn nur wenige Werte geändert wurden
- Geheimnisse durch Platzhalter ersetzen
- Quelle und Modversion dokumentieren
- Änderung im Changelog erfassen
