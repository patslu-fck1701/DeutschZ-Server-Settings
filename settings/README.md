# Settings

Hier werden ausschließlich selbst gepflegte und bereinigte Servereinstellungen abgelegt.

- `shared/`: identisch für Test und Live
- `local/`: lokale Testabweichungen ohne Geheimnisse
- `live/`: bereinigte Live-Einstellungen ohne Geheimnisse

Keine kompletten DayZ-, Mission-, Profil- oder Workshop-Verzeichnisse kopieren. Jede Unterstruktur soll eine kurze README mit Quelle, Version und Zweck enthalten.
